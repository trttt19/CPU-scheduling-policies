# CPU scheduling policies
This project implements various CPU scheduling algorithms used in operating systems to manage process execution efficiently
The algorithms are implemented in C++ 
## Implemented Algorithms
1. FCFS (First Come First Serve)
2. RR (Round Robin)
3. SPN (Shortest Process Next)
4. SRT (Shortest Remaining Time)
5. HRRN (Highest Response Ratio Next)
6. FB-1 (Feedback where all queues have q=1)
7. FB-2i (Feedback where all queues have q=2^i)
8. Aging
## Features 
- Trace mode: visualize process switching over the CPU
- Stats mode: Calculate and display scheduling metrics like completion time, turnaround time, and waiting time.
